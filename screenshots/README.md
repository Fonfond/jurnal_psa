# Скриншоты к руководству пользователя и администратора

Иллюстрации к [36_Руководство_пользователя_и_администратора.md](../36_Руководство_пользователя_и_администратора.md). Сняты 25.11.2026 для демонстрационного контура, данные вымышленные (seed + смена/виза/заземление/конфликт, созданные для иллюстрации).

## Как получены

- изолированный API: `ENV_FILE=.data/docs-shots.env` (PGlite `.data/docs-shots-pglite`, порт 3212, `AUTH_PROVIDER=dev`, `SIGNATURE_PROVIDER=simple`);
- web: `vite` на `127.0.0.1:5174` с `VITE_API_URL=http://127.0.0.1:3212/v1` (без production-сборки);
- браузер: headless Microsoft Edge (`--headless=new`, окно 1280×900, `deviceScaleFactor=1`), вход администратором `admin@logbook.local`, затем переходы по маршрутам и `Page.captureScreenshot`;
- для наполнения использованы seed-данные и демонстрационные действия: проверка записи, сдача/приёмка смены, виза журнала, событие заземления через `sync/push`, конфликт редактированием проверенной записи, WORM-экспорт, retention-run и backup-checkpoint.

Повторная съёмка (после изменения интерфейса) выполняется теми же шагами; имена файлов стабильны — ссылки в руководстве не меняются.
