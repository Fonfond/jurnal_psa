# 47. Диагностика: ручной объект (site_name_raw)

Дата: 28.11.2026  
Режим: демо-пилот, без изменения production-статуса (FAIL).

## 1. Что проверено

| Проверка | Результат |
|---|---|
| Объектов в S-03 dropdown у worker | **3** (`Подстанция 110/10 кВ`, `Опора ЛЭП №42`, `Склад ГПМ`) |
| Объектов в snapshot/админке | **3**, те же |
| Ограничение по правам | **Нет**: `dictionaries/snapshot` отдаёт все sites, worker видит все |
| Пагинация | **Нет**: snapshot отдаёт полный список, лимита нет |
| Поиск по объекту | **Нет**: только `<select>` без фильтра/ручного ввода |
| Причина | **B** — справочник полный, права не мешают; UX не даёт ввести объект вне справочника |

## 2. Причина A/B/C

- **A (права)** — не подтверждена: worker видит все 3 объекта.
- **C (данные не загружены)** — не подтверждена: snapshot содержит 3, dropdown показывает 3.
- **B (пагинация/нет поиска)** — подтверждена: список короткий и без поиска; главное — нет fallback-ввода.

## 3. Решение

Добавить `site_name_raw` + `site_binding_status` по образцу
`permit_number_raw` / `permit_binding_status`:

- запись сохраняется всегда, даже если объекта нет в справочнике;
- сервер при синхронизации нормализует имя (регистр, пробелы, ё→е) и пытается связать;
- не найдено → `not_found`, запись остаётся;
- автоматически Site не создаётся;
- supervisor/admin разбирают очередь unresolved и привязывают/создают объект.

## 4. Границы

- Permit, импорт нарядов и бизнес-логику журнала не трогаем.
- Site не удаляем и автоматически не создаём.
- Production-статус не меняем.

## 5. Реализовано

- миграция `0020_site_name_raw.sql`: `site_name_raw`, `site_binding_status`, `site_raw_ignores`;
- S-03: dropdown + «Другой объект» + автодополнение; сохранение не блокируется;
- сервер: нормализация (регистр, пробелы, ё→е), `linked`/`not_found`, raw сохраняется для аудита;
- S-05: raw в карточке, бейдж «Объект не в справочнике», supervisor/admin «Привязать к справочнику»;
- admin `/admin/sites`: очередь unresolved, создать/привязать/игнорировать;
- API: `GET /admin/sites/unresolved`, `POST /admin/sites/from-raw`, `POST /admin/sites/bind-from-raw`, `POST /admin/sites/ignore-raw`;
- Site автоматически не создаётся.
