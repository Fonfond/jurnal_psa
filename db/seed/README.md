# Детерминированный seed

| Параметр | Значение |
|---|---|
| Файл | `seed.ts` |
| Запуск | `npm run db:seed` (из корня) |
| Пароль | `DEV_SEED_PASSWORD`, по умолчанию `Logbook!2026` |
| Демо-фикстуры | `SEED_DEMO_DATA=true` включает 3 синтетических наряда и 5 записей; по умолчанию **выключены** |
| Идемпотентность | `ON CONFLICT DO NOTHING`; повторный запуск не создаёт дублей |

## Что создаётся

| Сущность | Количество | Идентификаторы |
|---|---|---|
| Подразделения | 2 | `01930000-…-0001`, `…-0002` |
| Пользователи | 3 | `…-0101` worker, `…-0102` supervisor, `…-0103` admin |
| Устройства | 3 | `…-0201`…`…-0203` |
| Типы работ | 3 | `…-0301`…`…-0303` |
| Объекты | 2 | `…-0401`, `…-0402` |
| Шаблоны | 2 | `…-0501`, `…-0502` |
| Причины | 3 | `…-0601`…`…-0603` |
| Наряды | 0 или 3 | только при `SEED_DEMO_DATA=true` |
| Записи | 0 или 5 | только при `SEED_DEMO_DATA=true` |

HLC-значения фиксированы для тестовых фикстур: `1795000000000:00001:seed0001` … `…:00005:seed0001`.

## Записи (только demo fixtures)

| ID | Автор | Статус | Особенность |
|---|---|---|---|
| `…-0801` | worker | active | наряд active, проверена руководителем |
| `…-0802` | worker | active | офлайн, ручная корректировка времени |
| `…-0803` | worker | active | voice/on_device, наряд closed, флаг риска |
| `…-0804` | supervisor | active | проверка качества |
| `…-0805` | worker | deleted | soft delete |

## Замечания

- Пароли хранятся в `user_credentials` (dev-аутентификация, ADR-22).
- При смене `DEV_SEED_PASSWORD` старые хэши не обновляются: удалите `.data/pglite` и повторите seed.
- Для демо по умолчанию **нет придуманных нарядов и записей**: импортируйте реальные наряды (CSV/JSON) и создавайте записи вручную.
- Реальные ПДн и номера нарядов в тестовых фикстурах не используются.
