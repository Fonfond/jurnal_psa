# `poc/data/` — тестовые наборы

| Параметр | Значение |
|---|---|
| Назначение | Синтетические данные для G1–G3 |
| ПДн | Запрещены. Голоса — только с письменным согласием; номера нарядов — вымышленные |
| Хранение | Локально, вне репозитория продукта; удаляются после отчёта PoC |
| Контроль | SHA-256 в `poc/results/artifacts.csv` |

---

## 1. Аудиокорпус (G1)

| Параметр | Значение |
|---|---|
| Объём | 2 часа |
| Дикторы | 3 |
| Шум | 70 / 80 / 90 дБ |
| Дистанция | 0,3 / 0,5 / 1,0 м |
| Длительность фразы | 10–15 с |
| Формат эталона | WAV, 16 кГц, моно, 16 бит |
| Транскрипты | UTF-8, нормализованные (числа цифрами, без пунктуации, `ё`→`е`) |

### Манифест `corpus_manifest.csv`

| Колонка | Правило |
|---|---|
| `file_id` | `g1_0001`… |
| `speaker_id` | `spk01`…`spk03` |
| `noise_db` | 70 / 80 / 90 |
| `distance_m` | 0.3 / 0.5 / 1.0 |
| `duration_s` | Число секунд |
| `transcript_path` | Относительный путь к `.txt` |
| `domain_terms` | Через `;`, до 10 терминов |

**Требования к разметке:** двойная разметка, расхождение < 2%, арбитраж третьим аннотатором.

---

## 2. Набор G2

| Набор | Объём | Правила генерации |
|---|---|---|
| `entries_10k.jsonl` | 10 000 записей | Текст 200–2000 символов, 10% с нарядом, 30% с 1–3 ревизиями |
| `outbox_10k.jsonl` | 10 000 операций | 70% create, 25% update, 5% delete; `op_id` UUID v7 |
| `revisions_5k.jsonl` | 5 000 ревизий | diff ≤ 8 КБ |
| `quota_filler.bin` | до 200 МБ | Заполнение хранилища, генерируется скриптом |

**Требования:** одинаковый набор для всех устройств; контрольная сумма фиксируется; генератор — в `poc/tools/`.

---

## 3. Набор G3

| Набор | Объём | Правила |
|---|---|---|
| `entities_1k.jsonl` | 1 000 сущностей | version 1–10, HLC фиксированной ширины |
| `changes_1k.jsonl` | 1 000 изменений | upsert/delete, `seq` 1…1000 |
| `conflicts_c01_c12.json` | 12 сценариев | По 20 прогонов, разные порядки доставки |
| `clock_drift.json` | 3 сценария | +1 ч, −1 ч, +1 год |

**Требования:** эталонный результат для каждого сценария хранится рядом (`*.expected.json`); расхождение — дефект прототипа.

---

## 4. Именование и версии

```
entries_10k.v1.jsonl
outbox_10k.v1.jsonl
corpus_manifest.v1.csv
conflicts_c01_c12.v1.json
```

Версия набора повышается при изменении состава или правил генерации; старые версии не удаляются до подписания отчёта.

---

## 5. Проверка перед прогоном

- [ ] Нет реальных ФИО, телефонов, номеров нарядов.
- [ ] Транскрипты нормализованы по правилам.
- [ ] Контрольные суммы совпадают с `artifacts.csv`.
- [ ] Объёмы соответствуют таблицам.
- [ ] Данные не содержат битых строк (валидация JSONL/CSV).
