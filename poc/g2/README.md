# G2 — прототип IndexedDB

| Параметр | Значение |
|---|---|
| Гейт | G2 (`12_План_PoC_Этап1.md`, раздел 6) |
| Статус | Исполняемый harness; прогон 24.11.2026 — **partial** (desktop Chromium D6; iOS/квоты/вытеснение не проверены) |
| В поставку | Не входит |

## 1. Тестовая схема

| Store | Ключ | Поля (минимум) |
|---|---|---|
| `entries` | `id` | `text`, `version`, `sync_status`, `performed_at` |
| `outbox` | `op_id` | `entity_id`, `op_type`, `status`, `attempts` |
| `revisions` | `id` | `entry_id`, `revision_no`, `diff` |
| `meta` | `key` | `schema_version`, `last_sync_seq` |

Схема **не является** продуктовой; она нужна только для проверки механики.

## 2. Планируемые файлы

| Файл | Ответственность |
|---|---|
| `harness.html` | Страница-стенд и кнопки сценариев |
| `schema.*` | Открытие базы, версия, stores, индексы |
| `tx.*` | Атомарная запись: entry + op + revision |
| `quota.*` | Заполнение до `QuotaExceededError`, восстановление |
| `export.*` | JSON-экспорт и импорт |
| `migrate.*` | v1→v2, бэкап, откат при ошибке |
| `locks.*` | Web Locks, две вкладки |

## 3. Инварианты

1. Нет записи без операции и наоборот.
2. Очередь не удаляется при очистке кэшей.
3. Экспорт содержит все несинхронизированные записи.
4. Миграция либо завершена, либо откатана; промежуточного состояния нет.
5. Две вкладки не создают дублей.

## 4. Ограничения

- Реальное вытеснение ОС и 7-дневный лимит Safari не воспроизводятся; фиксируется документальное поведение и косвенные проверки.
- Никаких продуктовых миграций и продуктовой схемы.

## 5. Запуск и результат

```powershell
node poc/tools/run-g2.mjs
```
