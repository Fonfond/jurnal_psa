# G1 — прототип on-device ASR

| Параметр | Значение |
|---|---|
| Гейт | G1 (`12_План_PoC_Этап1.md`, раздел 5) |
| Статус | Исполняемый harness; прогон 24.11.2026 — **blocked/fail** (нет модели, корпуса, устройств D1–D7) |
| В поставку | Не входит |

## 1. Конвейер

```
getUserMedia → capture (16 кГц, моно) → chunker (20 с, перекрытие 2 с)
→ ASR-адаптер (WASM, Web Worker) → склейка → нормализация → замеры
```

## 2. Планируемые файлы

| Файл | Ответственность |
|---|---|
| `harness.html` | Минимальная страница-стенд, без продуктового UI |
| `capture.*` | Захват микрофона, ресемплинг, индикатор уровня |
| `chunker.*` | Нарезка 20 с, перекрытие 2 с, склейка без дублей |
| `asr/adapter.*` | Загрузка модели, целостность, вызов в Worker |
| `metrics.*` | RTF, пиковая память, тайминги, запись в CSV |
| `scenarios.*` | 12 кейсов POC-G1-01…12 |

## 3. Контракты модулей

| Интерфейс | Вход | Выход |
|---|---|---|
| `capture.start()` | — | поток 16 кГц моно |
| `chunker.push(pcm)` | PCM-буфер | массив чанков с временными метками |
| `asr.transcribe(chunk)` | чанк | `{ text, latencyMs }` |
| `metrics.record(event)` | событие | строка CSV |

## 4. Метрики

- RTF = `latencyMs / audioDurationMs`.
- Пиковая память — `usedJSHeapSize` + оценка WASM.
- Кратность падений — число падений / число запусков.
- WER — по нормализованному тексту и эталону.

## 5. Ограничения

- Никакого продуктового UI, авторизации, синхронизации.
- Аудио не покидает устройство и удаляется после прогона.
- Модель только локальная, ≤ 40 МБ, SHA-256 проверяется.
- Прототип не оптимизируется сверх требований гейта.

## 6. Запуск и результат

```powershell
node poc/tools/run-g1.mjs
```
