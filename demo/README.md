# Logbook — демонстрационный комплект

Локальный сценарий для показа ЭОЖ «Logbook» без реальных данных и без production-инфраструктуры. Использует PGlite, seed-данные и Vite-прокси.

## 1. Требования

- Windows 10/11, PowerShell 5.1+ или PowerShell 7;
- Node.js ≥ 22 и npm 11;
- свободные порты `3001` (API) и `5173` (web).

## 2. Быстрый запуск

```powershell
npm install
npm run demo:start
```

Скрипт `demo/start.ps1`:

1. собирает `@logbook/shared`;
2. выполняет идемпотентный `db:seed`;
3. запускает API и web в отдельных окнах;
4. открывает `http://localhost:5173`.

Если PowerShell блокирует скрипты:

```powershell
pwsh -ExecutionPolicy Bypass -File demo/start.ps1
```

Или запустите вручную:

```powershell
npm run build:shared
npm run db:seed
npm run dev:api     # http://localhost:3001/v1
npm run dev:web     # http://localhost:5173
```

## 3. Учётные записи

Пароль: `Logbook!2026`.

| Роль | Email | Что показывает |
|---|---|---|
| Сотрудник | `worker@logbook.local` | свои записи, офлайн-создание |
| Руководитель | `supervisor@logbook.local` | проверка, конфликты |
| Администратор | `admin@logbook.local` | аудит, пользователи, импорт нарядов |

На экране входа есть кнопки быстрого dev-входа.

## 4. Сценарий на 7–10 минут

1. **Вход сотрудником** → «Сотрудник». В ленте 3 активные seed-записи.
2. **Офлайн-запись**:
   - DevTools → Network → Offline;
   - «+ Запись» → заполнить текст, тип работ, объект;
   - «Сохранить запись» → карточка показывает «Ожидает»;
   - вернуть Online.
3. **Синхронизация** → «Синхронизировать» на экране синхронизации. Статус меняется на «Синхронизировано».
4. **Проверка руководителем**:
   - выйти, войти как «Руководитель»;
   - открыть запись сотрудника → «Проверить».
5. **Конфликт**:
   - снова войти сотрудником;
   - открыть проверенную запись → «Изменить» → сохранить;
   - перейти в «Конфликты»; появится запись для разбора.
6. **Наряды**: открыть «Наряды» — 3 seed-наряда. PDF отключён (`TODO(OQ-03)`).
7. **Админ**: войти администратором → «Синхронизация» / аудит; импорт CSV можно показать через `demo/import-permits.ps1`.

## 5. Импорт демонстрационных нарядов

При запущенном API:

```powershell
npm run demo:permits
```

Скрипт `demo/import-permits.mjs` входит администратором, берёт `demo/permits.csv` и вызывает `POST /v1/admin/permits/import`. Повторный запуск идемпотентен по `(source_id, external_id)`.

## 6. Сброс

```powershell
npm run demo:reset
```

Скрипт удаляет **только** `.data/pglite` и заново выполняет seed. Подтверждение запрашивается.
