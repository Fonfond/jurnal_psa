## 1. Границы

**Разрешено в `poc/`:**

- минимальные HTML-страницы-стенды без продуктового UI;
- скрипты захвата аудио, чанкинга, замеров;
- прототип хранилища с тестовой схемой;
- прототип сервера синхронизации и merge на синтетических данных;
- генераторы тестовых данных и CSV-отчётов.

**Запрещено:**

- импорт кода из продуктового репозитория и обратно;
- продуктовые схемы БД, API-контракты, аутентификация, UI-компоненты;
- установка зависимостей в продуктовый проект;
- реальные ПДн, реальные голоса без согласия, реальные номера нарядов;
- деплой куда-либо, кроме локального стенда.

**Правило удаления:** после подписания отчёта PoC каталог `poc/` архивируется и исключается из поставки; выводы переносятся в документы, код — нет.

- Safari Web Inspector: Timelines, Storage, Console.

- Запись экрана для фиксации поведения (по требованию).

## 5. Шаблоны CSV для `poc/results/`

Файлы созданы с заголовками; заполняются вручную или скриптом.

| Файл | Назначение | Колонки |
|---|---|---|
| `g1_measurements.csv` | Замеры ASR | `run_id,date_utc,device_id,device_class,os,browser,browser_version,model_id,model_size_mb,scenario,audio_file,audio_duration_s,latency_s,rtf,peak_mem_mb,wer,crashed,notes` |
| `g2_measurements.csv` | Замеры хранилища | `run_id,date_utc,device_id,os,browser,scenario,records,ops,quota_mb,persist_granted,atomic_ok,data_loss,export_ok,restore_ok,migration_ok,duration_ms,notes` |

| `devices.csv` | Паспорт устройств | `device_id,model,class,os,browser,browser_version,screen,notes` |

**Правила заполнения:**

1. `run_id` — `G1-0001`, `G2-0001`, `G3-0001`; сквозная нумерация.

3. Логические поля — `true/false`, числа — точка как разделитель.
4. Пустые значения запрещены; для неприменимых — `n/a`.
5. `notes` — только факты (температура, аномалии), без оценок.

## 6. Архитектура прототипов в `poc/`

```
poc/
├── README.md                 # границы, запуск, порты
├── g1/                       # on-device ASR
│   ├── harness.html          # страница-стенд (не продукт)
│   ├── capture.*             # getUserMedia, AudioWorklet/MediaRecorder
│   ├── chunker.*             # 20 с, перекрытие 2 с
│   ├── asr/                  # адаптер модели (WASM)
│   ├── metrics.*             # RTF, память, тайминги
│   └── scenarios.*           # 12 кейсов G1
├── g2/                       # IndexedDB
│   ├── harness.html
│   ├── schema.*              # stores: entries, outbox, revisions, meta
│   ├── tx.*                  # атомарность
│   ├── quota.*               # заполнение, QuotaExceededError
│   ├── export.*              # экспорт/импорт
│   ├── migrate.*             # v1→v2 с бэкапом и откатом
│   └── locks.*               # Web Locks, две вкладки
├── g3/                       # синхронизация
│   ├── server.*              # HTTP: push/changes, in-memory или Postgres
│   ├── hlc.*                 # формат, tick, merge
│   ├── merge.*               # C-01…C-12
│   ├── change_log.*          # seq, страницы
│   ├── idempotency.*         # op_id, TTL
│   ├── batch.*               # порядок одной сущности
│   └── scenarios.*           # 24 кейса G3
├── data/                     # корпус, сиды, манифесты
├── results/                  # CSV и логи
└── tools/                    # генераторы и конвертеры
```

### 6.1. G1: конвейер

| Модуль | Ответственность | Вход/выход |
|---|---|---|
| `capture` | Захват микрофона, 16 кГц моно | аудиопоток → PCM-буфер |
| `chunker` | Нарезка 20 с с перекрытием 2 с, склейка | PCM → чанки → текст |
| `asr` | Загрузка модели, распознавание в Worker | чанк → текст, латентность |
| `metrics` | RTF, пиковая память, тайминги | события → CSV |
| `scenarios` | 12 кейсов G1 | сценарий → прогон |

**Ключевые ограничения:** UI минимальный, без продуктовой вёрстки; модель только локальная; аудио не покидает устройство; после прогона аудио удаляется.

### 6.2. G2: хранилище

| Модуль | Ответственность | Проверка |
|---|---|---|
| `schema` | Stores и индексы тестовой схемы | Открытие, версия |
| `tx` | Запись + операция + ревизия в одной транзакции | 100/100 |
| `quota` | Заполнение до отказа, обработка `QuotaExceededError` | Очередь цела |
| `export` | JSON-экспорт и восстановление | 100% |
| `migrate` | Миграция 10 000 записей, бэкап, откат | Без потерь |
| `locks` | Web Locks, две вкладки | Нет дублей |

**Ограничение:** реальное вытеснение ОС и 7-дневный лимит Safari не воспроизводятся; фиксируется документальное поведение и косвенные проверки.

### 6.3. G3: синхронизация

| Модуль | Ответственность | Проверка |
|---|---|---|
| `hlc` | Формат 13+5+8, `tick`, `merge` | Лексикографический порядок |
| `merge` | Правила C-01…C-12, приоритет роли | 12/12, без потерь |
| `change_log` | `seq`, страницы, `has_more` | Без пропусков |
| `idempotency` | `op_id` → ответ, TTL | 5 повторов = 1 результат |
| `batch` | Порядок операций одной сущности | Без обгона |
| `server` | `POST /push`, `GET /changes` | p95 ≤ 400 мс |
| `scenarios` | 24 кейса G3 | Детерминизм 100/100 |

**Ключевое ограничение:** прототип не содержит аутентификации, прав и продуктовой модели; только механика merge, HLC, `seq`, идемпотентности и порядка.

**Ready (D1):**

- все устройства из раздела 2.1 подготовлены и внесены в `devices.csv`;
